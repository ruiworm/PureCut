## ⚡ 为什么选择 PureCut？

在电商短视频二创与混剪中，创作者通常面临以下痛点：
1. **原片有人物口播无法复用**：需要一帧一帧手动去切纯商品镜头，耗时耗力。
2. **原片字幕与贴纸无法彻底清除**：满屏牛皮癣水印、旧台词残留，二创容易被平台判定为同质化搬运。
3. **剪辑流程繁琐割裂**：剪映/PR切片、剪画幅、导出配音、重新对齐字幕，效率极低。

**PureCut** 为解决上述问题而生，提供从**“素材提纯”**到**“矩阵成品”**的全自动化工业流水线：

| 核心能力 | 技术实现 | 带来价值 |
|---|---|---|
| ✂️ **去人像提纯与空镜提取** | MediaPipe 智能姿态/人脸检测 | 自动剔除口播人物，提取纯净商品镜头；支持“智能手模保留”与“全静物严苛模式” |
| 🔍 **超轻量级字幕区域初筛** | PP-OCRv4-det ONNX (~4.6MB) | 单帧 10ms CPU 极速推理，自动定位底部原字幕区域并平滑抹除 |
| 🎯 **交互式框选消除 (ROI Eraser)** | 监视器实时画框 + FFmpeg 动态滤镜 | 在画面上鼠标直接拖拽拉框，精准消除残留原字、平台水印与贴纸 |
| ✍️ **所见即所得爆款花字** | 监视器拖拽定位 + 4 款爆款视觉风格 | 支持画面直接拖拽调整垂直位置；预设爆款亮黄、极简纯白、数码青蓝、黑金胶囊 |
| 🎙️ **电商高转化配音矩阵** | 火山豆包带货官方同款 + CosyVoice2 + 本地免Key | 接入灿灿/爽快/生动/醇厚等顶级带货音色；支持电商价格符号自动归一化防读错 |
| ⚡ **极速流拷贝裂变合成** | FFmpeg 8.x `-c copy` 极速架构 | ~0.1 秒秒级切片与导出，画质 0 损失，单机一天可轻松产出上百条差异化矩阵短视频 |

│ • 本地素材目录树 │ 【步骤 1: 纯净底片】│ • 9:16 电商手机实机监视器     │ • 提纯空镜池     │

### 1. 两步极简剪辑流
- **步骤一：生成纯净底片**
  - **彻底静音**：100% 剥离原音频轨（`-an`），彻底清除原声主播杂音与旧背景音乐。
  - **人像剔除**：智能识别人物出镜时间段，自动截取并保留纯净商品空镜。
  - **画幅适配**：一键切换 9:16（电商竖屏 1080x1920）、3:4（小红书）、16:9（横屏）或保持原片比例。
- **步骤二：审阅精修与包装**
  - **残留字幕框选消除**：在右侧监视器画面上鼠标拖拽拉框，精准框选残留的原字幕或牛皮癣。
  - **新字幕定制**：预设 顶部18%、居中50%、黄金75%、靠底85%，支持实时拖拽与花字样式选择。
  - **电商配音选择**：选择带货音色、语速，录入带货口播文案，支持一键试听。
  - **一键合成包装**：自动完成多轨对齐与渲染。

### 2. 监视器与多轨时间轴
- **平台安全区参考线 (Safe Zone)**：内置抖音/快手/小红书官方规范，实时标注顶部搜索关注栏（12%）、侧边互动栏（18%）、底部小黄车文案区（25%）与核心黄金展示区。
- **三轨对齐时间轴**：
  - **V1 视频轨**：清晰标记纯净空镜区间与人像剔除区间。
  - **A1 拟真带货配音轨**：波形展示与口播时长自适应对齐。
  - **T1 爆款花字字幕轨**：自动智能断句与安全区避让。

## 🚀 快速启动

### 方式一：桌面客户端模式（推荐，无地址栏原生体验）

双击运行根目录下的桌面启动程序：

```cmd
launch_desktop.bat
```

> **说明**：脚本会自动启动后台 Python 算法服务（端口 8765），并以 Electron 原生窗口打开 PureCut 工作台，获得沉浸式桌面级剪辑体验。

### 方式二：Python 命令行启动

```bash
# 1. 安装核心依赖
pip install -r requirements.txt

# 2. 启动 Studio Pro 工作台 (默认端口 8765)
python scripts/web_studio.py 8765
```

启动完成后，用浏览器访问：`http://127.0.0.1:8765`

## 🎙️ 配音引擎支持

PureCut 内置成熟的电商带货配音体系：

1. **火山引擎·豆包大模型 TTS**（抖音/剪映带货官方同款天花板）：
   - `zh_female_cancan` 灿灿（热情电商女声）
   - `zh_female_shuangkuai` 爽快（带货冲量女声）
   - `zh_female_shengdong` 生动（高质感种草女声）
   - `zh_male_chunhou` 醇厚（成熟数码男声）
   - `zh_male_yangguang` 阳光（年轻潮玩男声）
2. **硅基流动·CosyVoice 2**：Bella、Alex、Anna、Benjamin 等自然细腻的高性价比音色。
3. **本地离线 0 成本端点**：支持本地端口 9233（CosyVoice2-0.5B）与 50000（FastCosyVoice），完全离线免 Key 运行。
4. **微软 Edge-TTS**：晓晓、云希等 100% 永久免费音色。
5. **电商价格自动归一化**：内置货币符号正则解析，自动将 `¥39.9` 等价格转换为 `39.9元`，杜绝吞字漏读。
